# SOL-USDT 永续合约 · 日内均值回归策略研究报告

> 研究目标：**稳定收益**（月度正收益占比高、回撤可控、样本外可复现）
> 研究对象：OKX `SOL-USDT-SWAP`，日内（5m / 15m / 30m）四种均值回归方法
> 数据窗口：2025-10-16 → 2026-10-11（北京时间，361 天，仅已收盘 K 线）
> 复现方式：`python3 TRADE/mean_reversion_intraday_backtest.py`（纯标准库，零依赖）
> 报告日期：2026-10-11

# 第一部分 · 各方法的数据与对比

## 1. 研究设置

| 项目 | 说明 |
|---|---|
| 数据 | `DATA/` 下 5m（103,680 根）、15m（34,560 根）、30m（17,280 根），各覆盖整 360 天 |
| 执行模型 | 信号在收盘产生、**下一根开盘成交**（无未来函数）；止损盘中触发 |
| 日内约束 | 每日最后一根 K 线**强制平仓**（不留隔夜仓）；跨日信号作废；同一时间只持一个仓位 |
| 风控 | 2×ATR(14) 硬止损 + 4 小时时间止损（按周期折算：48/16/8 根）+ 日终平仓 |
| 成本模型 | 每边 = 手续费 + 滑点。四档：零成本 / 3bp（maker 类）/ **7bp（OKX VIP0 taker 5bp + 滑点 2bp，基准档）** / 11bp（劣化执行） |
| 验证方法 | 70/30 样本内/外切分（IS：2025-10-16 → 2026-06-24；OOS：2026-06-25 → 10-11）；月度收益一致性；四策略等权组合 |
| 参数原则 | **全部采用教科书默认参数，事前固定，不做任何优化**（避免曲线拟合）；四策略统一 60 根预热，保证回测窗口完全一致 |
| 市场背景 | 期间 SOL 从约 193 跌至约 110（买入持有 **-44.1%**，最大回撤 70.5%），是一个趋势性熊市年份 |

## 5. 稳定性验证：毛边际本身就不稳定

即使不考虑成本，毛边际是否稳定？看 IS / OOS 的毛夏普比率（零成本口径）：

| 方法 | 5m IS→OOS | 15m IS→OOS | 30m IS→OOS |
|---|---|---|---|
| A 布林带 | +0.58 → +2.21 | **-1.02 → +2.23** | **-0.34 → +2.07** |
| B RSI | -0.44 → +1.37 | -0.18 → -0.92 | -0.07 → +1.69 |
| C VWAP | +0.58 → +2.54 | **-1.44 → +3.41** | **-0.32 → +3.26** |
| D Z分数 | +1.13 → +0.03 | -1.11 → +0.12 | -0.16 → +0.20 |

**样本内为负、样本外为正，符号直接翻转**（15m/30m 的 A 和 C 最为典型）。原因：OOS 段（2026-06-25 之后）恰逢区间震荡市，利好均值回归；IS 段包含 2025Q4–2026H1 的趋势性下跌，逆势抢反弹被反复碾压。**一个依赖市场状态的边际不是稳定边际。**

月度正收益占比（基准成本档）同样说明问题：

| 方法 | 5m | 15m | 30m |
|---|---:|---:|---:|
| A 布林带 | 0 / 13 | 0 / 13 | 1 / 13 |
| B RSI | 0 / 13 | 1 / 13 | 2 / 13 |

13 个月里最好的配置也只有 3 个正收益月。**"稳定收益"目标在现有 12 个配置上均未达成。**

## 6. 行为特征：为什么亏？

以基准成本档的退出原因分布（signal=回归到位 / stop=止损 / time=超时 / eod=日终强平）：

| 方法·周期 | 平均持仓（根） | signal | stop | time | eod | 止损占比 |
|---|---:|---:|---:|---:|---:|---:|
| A·5m | 6.6 | 3131 | **3269** | 0 | 140 | 50% |
| C·5m | 13.7 | 535 | **1295** | 168 | 124 | 61% |
| B·30m | 5.8 | 52 | 174 | **239** | 68 | 33% |
| C·30m | 4.8 | **396** | 298 | 278 | 84 | 28% |

- 约一半交易以止损离场（2×ATR 止损被打穿），说明**逆势入场的方向错误率很高**；
- 胜率仅 41%~58%，且平均盈利单不足以覆盖平均亏损单 + 成本（PF 全部 < 1.1，零成本口径）；
- 组合分散也无效：四个策略高度同质（同为逆势抢回调），等权组合的亏损介于各成员之间，没有分散收益。

## 7. 第一部分结论

1. **基准成本下，四种日内均值回归 × 三个周期全部净亏损**，且月度几乎无正收益月——直接回答研究目标：**本年度数据上，这类策略无法提供稳定收益**。
2. 毛边际确实存在（5m 零成本 +43%），但其**量级（0.4~2.3bp/笔）远低于现实成本（≥2bp/边）**，且**IS/OOS 符号翻转、月度不稳定**——是状态依赖的噪声，不是可依赖的 alpha。
3. 相对最优的组合是 **30m 的 VWAP 回归（毛 +16.9%、胜率 58.1%、盈亏平衡 1.08bp/边）**和 **30m 的 RSI 回归（净亏最少 -53.1%）**——若继续研究，应从这里出发，而不是 5m。
4. 组合分散、拉长周期、弱化止损都只能"减亏"，无法翻正。

# 第二部分 · 策略本身：用了什么指标与方法

## 1. 共用日内交易框架（四种方法完全一致）

| 组件 | 规则 |
|---|---|
| 入场 | 信号在 K 线**收盘**判定，下一根 K 线**开盘价**成交（杜绝未来函数） |
| 方向 | 双向：超跌做多、超涨做空（永续合约天然支持） |
| 止损 | 入场价 ∓ 2×ATR(14)，盘中触发即离场（含滑点） |
| 时间止损 | 持仓满 4 小时强制离场（5m=48 根、15m=16 根、30m=8 根） |
| 日终平仓 | 北京时间每日最后一根 K 线收盘强制离场——**严格日内、零隔夜风险** |
| 跨日信号 | 收盘产生的信号若次日才开盘执行，一律作废 |
| 仓位 | 同一时间仅一笔，全仓 1 倍名义本金，收益按复利累计 |
| 预热 | 四策略统一前 60 根不出信号，回测窗口完全一致，保证公平对比 |

## 2. 方法 A：布林带均值回归（Bollinger Fade）

- **指标**：20 根收盘价 SMA ± 2 倍总体标准差（布林带），20 根为业界默认参数。
- **逻辑**：价格触及下轨（偏离均值 2 个标准差以上）→ 押注回归中轨；触及上轨 → 反向做空。
- **入场**：收盘 ≤ 下轨 → 做多；收盘 ≥ 上轨 → 做空。
- **离场**：收盘回到中轨（做多时 ≥ 中轨，做空时 ≤ 中轨）→ 下一根开盘离场。
- **适用场景**：震荡市中的极端偏离。**弱点**：单边趋势里"下轨之下还有下轨"，本数据 2025Q4–2026H1 的下跌正是如此——它在 5m 上交易 6,022 笔（日均 17 笔），止损占比 50%。

## 3. 方法 B：RSI 超买超卖回归（RSI Reversion）

- **指标**：Wilder RSI(14)（标准 14 周期）。
- **逻辑**：RSI ≤ 30 视为超卖 → 做多等反弹；RSI ≥ 70 视为超买 → 做空。
- **入场**：RSI ≤ 30 做多 / ≥ 70 做空。
- **离场**：RSI 回到 50 中轴（多头 ≥ 50、空头 ≤ 50）→ 下一根开盘离场。
- **适用场景**：经典动量衰竭判定。**弱点**：强趋势中 RSI 会长期钝化在极值区，"超卖更超卖"；本数据上它是唯一在 5m 零成本下也无毛利的方法（-7.2%），30m 上毛利 +7.5%、净亏最少（-53.1%），是**相对稳健**的版本。

## 4. 方法 C：日内锚定 VWAP 偏离回归（VWAP Reversion）

- **指标**：以北京时间每日 00:00 锚定的**累计 VWAP**（Σ典型价×量 / Σ量）及**日内累计成交量加权标准差 σ**（每日重置）；当日头 1 小时（按周期折算 12/4/2 根）不交易，等 σ 有意义。
- **逻辑**：VWAP 是日内交易者的平均成本锚。价格显著偏离 VWAP（±2σ）后向 VWAP 回归是日内最高频的形态之一，且**天然日内**——每天锚点重置，与"不留隔夜仓"完美契合。
- **入场**：收盘 ≤ VWAP - 2σ → 做多；≥ VWAP + 2σ → 做空。
- **离场**：收盘回到 VWAP → 下一根开盘离场。
- **适用场景**：全周期表现最均衡的方法（5m 零成本 +43.8%，30m 零成本 +16.9%、胜率 58.1% 为全场最高）。**弱点**：仍然逃不过成本鸿沟（盈亏平衡 1.08bp/边），且趋势日的单边偏离会被连续止损。

## 5. 方法 D：制度过滤 Z 分数回归（Regime-filtered Z-score）

- **指标**：60 根滚动 Z 分数 =（收盘 - SMA60）/ STD60；**效率系数 ER** = 60 根净位移 / 60 根路径总长（衡量趋势强度，0=纯震荡，1=单边直行）。
- **逻辑**：只在**震荡制度**（ER < 0.30）里做均值回归，试图避开方法 A/B 暴毙的单边趋势：Z ≤ -2 且 ER < 0.3 → 做多；Z ≥ +2 且 ER < 0.3 → 做空。
- **离场**：|Z| ≤ 0.5（接近均值）→ 下一根开盘离场；时间止损放宽到 6 小时。
- **适用场景**：制度过滤是均值回归研究的标准改进方向。**本数据的结果是教训**：即便加了 ER 过滤，15m/30m 零成本仍为负（-30.9% / -6.9%），说明单一 ER 阈值不足以识别"会回归"的震荡，反而过滤掉了部分盈利机会——**制度识别本身需要更精细的方法（如 ADX+波动率结构、Hurst 指数），是后续研究的核心方向。**

## 6. 成本模型细节

| 档位 | 每边成本 | 构成 |
|---|---:|---|
| gross | 0 | 理论毛边际 |
| low | 0.03% | maker 手续费 2bp + 滑点 1bp |
| **base** | **0.07%** | **OKX VIP0 taker 5bp + 滑点 2bp** |
| high | 0.11% | taker 6bp + 劣化滑点 5bp |

成本按边计：开仓、平仓各收一次；止损单同样计滑点。**未建模项**：资金费率（每 8 小时结算，日内持仓 <4h，影响通常 <1bp/笔，方向不定）、排队未成交风险（若改挂限价单）、极端行情的深度不足。

## 8. 基于证据的后续方向（按优先级）

1. **放弃 5m~30m 的独立日内均值回归**：毛边际 0.4~2.3bp/笔 对 现实成本 ≥2bp/边，结构性不可行——这不是优化参数能解决的。
2. **升级周期至 1H/2H**：单笔波动放大 2~4 倍，成本占比相应下降；`DATA/` 中已有 1H（8,640 根）/2H（4,320 根）数据可直接复用本引擎（改 `TIMEFRAMES` 配置即可）。
3. **强化制度识别**：ER 单阈值不够；建议 ADX + 已实现波动率分位 + Hurst 指数组合门控，只在"高震荡、无趋势"状态开启回归敞口。
4. **降低交易频率、提高单笔质量**：入场阈值 2σ → 2.5~3σ，等待极端偏离；以笔数换边际。
5. **maker 化执行**：入场用限价单挂 VWAP/轨道外侧（2bp/边），出场吃市价——把成本压到盈亏平衡附近，但需接受排队不成交风险。
6. **换一个思路**：把均值回归信号降级为**趋势策略的入场时机工具**（趋势方向上的回调入场），让趋势承担收益、回归负责择时——本次数据中趋势年是致命伤，反向利用它。
