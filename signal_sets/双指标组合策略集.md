# 双指标组合交易策略集（SOL 永续合约）

> 针对 SOL 永续合约（高波动、趋势性强、行情切换快），从 6 个指标（BOLL、MACD、RSI、DMI、MA、EMA）中两两组合，精选 10 个逻辑互补的策略。

## 策略一：EMA + RSI — 趋势回调策略

| 项目 | 内容 |
|:-----|:-----|
| **核心逻辑** | EMA 定大方向，只做顺势单；RSI 找回调入场点 |
| **适用行情** | 明确趋势行情 |
| **1. 行情识别** | EMA 多头排列 = 多头趋势，只做多；空头排列 = 空头趋势，只做空 |
| **2. 开仓** | 上升趋势中，RSI 回调至 40~50 区间后再度向上 → 做多 |
| **3. 加仓** | 价格回踩 EMA_short 获得支撑 + RSI 从中界反弹 → 加仓 |
| **4. 止盈** | RSI > 70（超买）或 固定比例止盈，先到先触发 |
| **5. 止损** | EMA 死叉 或 跌破 EMA_long |
| **适合 SOL 的原因** | SOL 趋势性强，回调不深，顺势做回调胜率高 |

---

## 策略二：BOLL + RSI — 均值回归策略

| 项目 | 内容 |
|:-----|:-----|
| **核心逻辑** | BOLL 划定价格通道边界，RSI 确认超买超卖，做高抛低吸 |
| **适用行情** | 震荡行情 / 区间整理 |
| **1. 行情识别** | 布林带带宽收窄（处于近期低位）= 震荡市 |
| **2. 开仓** | 价格触及下轨 + RSI < 30 后回升 → 做多；价格触及上轨 + RSI > 70 后回落 → 做空 |
| **3. 加仓** | 二次探底（第二次触下轨不创新低）+ RSI 底背离 → 加仓 |
| **4. 止盈** | 价格回归中轨（%B ≈ 0.5）或 固定比例止盈 |
| **5. 止损** | 收盘价有效突破轨线（震荡转趋势） → 止损离场 |
| **适合 SOL 的原因** | SOL 震荡期波动幅度大，区间利润空间足 |

---

## 策略三：DMI + MACD — 强趋势突破策略

| 项目 | 内容 |
|:-----|:-----|
| **核心逻辑** | DMI 的 ADX 过滤掉震荡市，只在有趋势时交易；MACD 确认入场时机 |
| **适用行情** | 强趋势行情 |
| **1. 行情识别** | ADX > 25 = 有趋势，ADX < 20 不交易 |
| **2. 开仓** | ADX > 25 + MACD 零上金叉 → 做多；ADX > 25 + MACD 零下死叉 → 做空 |
| **3. 加仓** | ADX 持续上升 + MACD 红柱/绿柱放大 → 加仓 |
| **4. 止盈** | ADX 拐头向下（趋势减弱）或 固定比例止盈 |
| **5. 止损** | MACD 反向交叉 + ADX 回落 → 止损 |
| **适合 SOL 的原因** | SOL 经常有单边大行情，用 ADX 过滤后只吃趋势段 |

---

## 策略四：BOLL + MACD — 波动率突破策略

| 项目 | 内容 |
|:-----|:-----|
| **核心逻辑** | 布林带从收敛突然开口 = 波动率放大 + 趋势启动；MACD 确认方向 |
| **适用行情** | 震荡转趋势 / 突破行情 |
| **1. 行情识别** | 带宽收窄至极值 → 即将变盘 |
| **2. 开仓** | 价格突破上轨 + MACD 红柱放大 → 做多；价格跌破下轨 + MACD 绿柱放大 → 做空 |
| **3. 加仓** | 突破后回踩轨线获得支撑/压力 + MACD 柱状继续放大 → 加仓 |
| **4. 止盈** | 带宽从扩大转缩小 或 固定比例止盈 |
| **5. 止损** | 价格跌回轨线内 + MACD 柱状缩量 → 假突破止损 |
| **适合 SOL 的原因** | SOL 经常"横久必涨/跌"，收敛后的突破行情爆发力强 |

---

## 策略五：MACD + RSI — 双背离反转策略

| 项目 | 内容 |
|:-----|:-----|
| **核心逻辑** | MACD 背离 + RSI 背离双重确认顶部/底部，做反转交易 |
| **适用行情** | 趋势末端 / 拐点行情 |
| **1. 行情识别** | 趋势运行一段时间后，价格创新高/新低但动量减弱 |
| **2. 开仓** | MACD 底背离 + RSI 底背离（双背离）+ MACD 金叉确认 → 做多 |
| **3. 加仓** | 反弹后回踩不破前低 + RSI 在 50 上方企稳 → 加仓 |
| **4. 止盈** | RSI 到达 60~70 区间 或 固定比例止盈 |
| **5. 止损** | 价格再创新低且双背离消失 → 反转失败止损 |
| **适合 SOL 的原因** | SOL 暴涨暴跌后经常有 V 型反转，双背离抄底逃顶胜率高 |

## 策略六：MA + BOLL — 均线布林带通道策略

| 项目 | 内容 |
|:-----|:-----|
| **核心逻辑** | MA 判断大趋势方向，BOLL 在趋势方向内做波段，中轨 = MA 本身 |
| **适用行情** | 中等强度趋势 / 上升通道 |
| **1. 行情识别** | MA 多头排列 + 价格在中轨上方 = 多头通道 |
| **2. 开仓** | 价格回调至下轨/中轨获得支撑 + MA 方向未变 → 做多 |
| **3. 加仓** | 价格突破上轨 + MA 斜率加大 → 加仓 |
| **4. 止盈** | 价格触及上轨 或 固定比例止盈 |
| **5. 止损** | 收盘价跌破中轨（MA） → 趋势破坏止损 |
| **适合 SOL 的原因** | SOL 上升/下降通道清晰，用布林带做波段节奏刚好 |

---

## 策略七：DMI + RSI — 趋势过滤震荡策略

| 项目 | 内容 |
|:-----|:-----|
| **核心逻辑** | DMI 先判断有没有趋势，有趋势就用 RSI 做顺势回调，没趋势就观望 |
| **适用行情** | 趋势行情中的回调入场 |
| **1. 行情识别** | ADX > 25 = 有趋势，+DI > -DI 只做多，反之只做空；ADX < 20 不交易 |
| **2. 开仓** | 多头趋势中，RSI 回落至 40 附近后反弹 → 做多 |
| **3. 加仓** | RSI 回踩 50 中界线后再度向上 + ADX 仍在上升 → 加仓 |
| **4. 止盈** | RSI > 70（超买） 或 固定比例止盈 |
| **5. 止损** | ADX 拐头向下 + RSI 跌破 50 → 止损 |
| **适合 SOL 的原因** | 用 ADX 过滤掉 SOL 的震荡期，只在趋势期出手，大幅提高胜率 |

---

## 策略八：MA + DMI — 经典趋势跟踪策略

| 项目 | 内容 |
|:-----|:-----|
| **核心逻辑** | MA 双均线定方向，DMI 的 ADX 确认趋势强度，只在强趋势中持仓 |
| **适用行情** | 中长线趋势 |
| **1. 行情识别** | MA 金叉 + ADX > 25 且上升 = 多头趋势确立 |
| **2. 开仓** | MA 金叉后回踩 MA_long 获得支撑 + ADX 仍在 25 以上 → 做多 |
| **3. 加仓** | ADX 从 25 升到 40 过程中 + 价格回踩 MA_short → 加仓 |
| **4. 止盈** | ADX 从高位（>40）回落 或 固定比例止盈 |
| **5. 止损** | MA 死叉 或 ADX 跌回 25 以下 → 止损离场 |
| **适合 SOL 的原因** | SOL 大趋势行情持续时间长，经典趋势跟踪能吃到主升浪 |

## 策略九：BOLL + DMI — 自适应波段策略

| 项目 | 内容 |
|:-----|:-----|
| **核心逻辑** | DMI 判断当前是趋势市还是震荡市，自动切换 BOLL 的用法——趋势市用突破，震荡市用回归 |
| **适用行情** | 全行情自适应 |
| **1. 行情识别** | ADX > 25 = 趋势市（用 BOLL 突破策略）；ADX < 20 = 震荡市（用 BOLL 高抛低吸） |
| **2. 开仓** | 趋势市：突破上轨做多 / 跌破下轨做空；震荡市：触下轨做多 / 触上轨做空 |
| **3. 加仓** | 趋势市：回踩中轨支撑加仓；震荡市：二次触轨确认加仓 |
| **4. 止盈** | 趋势市：带宽缩小止盈；震荡市：回归中轨止盈 / 固定比例止盈 |
| **5. 止损** | 趋势市：跌破中轨止损；震荡市：突破轨线止损（说明变趋势了） |
| **适合 SOL 的原因** | SOL 行情切换快（震荡→趋势→震荡），自适应策略不用人工判断 |

---

## 策略十：EMA + MACD — 动量趋势策略

| 项目 | 内容 |
|:-----|:-----|
| **核心逻辑** | EMA 判断大趋势方向，MACD 柱状变化作为入场和加仓的领先信号 |
| **适用行情** | 趋势行情（中短线） |
| **1. 行情识别** | EMA 多头排列 + MACD 在零轴上方 = 多头主导 |
| **2. 开仓** | EMA 方向向上 + MACD 绿柱转红柱（柱状由负转正）→ 做多 |
| **3. 加仓** | MACD 红柱持续放大（加速度向上）+ EMA 斜率加大 → 加仓 |
| **4. 止盈** | MACD 红柱连续缩小 或 固定比例止盈 |
| **5. 止损** | MACD 死叉 + 价格跌破 EMA_short → 止损 |
| **适合 SOL 的原因** | MACD 柱状比金叉更早发出信号，适合 SOL 这种变化快的品种 |
| **注意** | EMA 和 MACD 有一定信息重叠（MACD 基于 EMA），优势是柱状的领先性，不是独立双确认 |

## 指标组合互补性分析

| 组合 | 互补性 | 说明 |
|:-----|:------:|:-----|
| BOLL + RSI | ★★★★☆ | 一个给价格边界，一个给动量极值，完美互补 |
| DMI + MACD | ★★★★★ | 一个判断趋势强度，一个确认入场时机，完全独立 |
| BOLL + DMI | ★★★★★ | 一个给价格通道，一个给趋势强度，维度完全不重叠 |
| EMA + RSI | ★★★★☆ | 趋势 + 震荡指标经典搭配 |
| MA + DMI | ★★★★☆ | 均线定方向 + ADX 定强度，经典趋势跟踪组合 |
| MACD + RSI | ★★★☆☆ | 都是动量类，但一个是趋势动量一个是震荡动量，有一定重叠 |
| MA + BOLL | ★★☆☆☆ | BOLL 中轨就是 MA，信息重叠度高 |
| EMA + MACD | ★★☆☆☆ | MACD 基于 EMA，信息重叠度最高 |

> **选择原则**：尽量选互补性高的组合，避免同类指标叠加。
