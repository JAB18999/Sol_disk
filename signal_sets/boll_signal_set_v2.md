# BOLL 三轨状态监测信号体系（V2）

- **版本**：2.0
- **适用品种**：SOL-USDT 永续合约
- **建议周期**：15m、30m、1H、2H
- **体系定位**：辅助交易监测，不独立承担开仓决策
- **监测核心**：上轨、中轨、下轨的方向、斜率、间距、曲率与相互关系

> 本体系不以“价格碰到哪条轨道”为核心，而是观察布林带三条轨道本身如何运行。通过三轨同向、开口、收口、平行、扭转和不对称变化，监测行情方向、趋势强弱、加速、衰减、震荡、突破准备及潜在反转。

---

## 一、指标基础

默认布林带参数：

```text
周期 N = 20
标准差倍数 K = 2
中轨 M = SMA(Close, N)
上轨 U = M + K × STD(Close, N)
下轨 L = M - K × STD(Close, N)
```

三轨含义：

- **中轨 M**：价格运行中枢，主要反映趋势方向；
- **上轨 U**：上方波动边界，反映上行波动及上方空间变化；
- **下轨 L**：下方波动边界，反映下行波动及下方空间变化；
- **U 与 L 的距离**：整体波动率；
- **U-M 与 M-L 的变化**：上下两侧波动结构。

理论上，同一时刻：

```text
U - M = M - L
```

但三条轨道各自相对上一根 K 线的变化速度可能不同，因此仍能形成扩张、收缩、同向平移和扭转等运行状态。

---

## 二、三轨监测变量

为了跨价格阶段、跨周期比较，建议使用归一化变化率。

### 2.1 单轨斜率

使用最近 `S = 3` 根 K 线计算：

```text
Slope_U = (U(t) - U(t-S)) / M(t-S)
Slope_M = (M(t) - M(t-S)) / M(t-S)
Slope_L = (L(t) - L(t-S)) / M(t-S)
```

状态阈值建议：

```text
Slope > +ε：向上
Slope < -ε：向下
|Slope| ≤ ε：走平
```

默认：

```text
ε = 0.001，即 0.1%
```

阈值应根据周期回测调整。

### 2.2 单轨瞬时方向

用于及时发现轨道拐点：

```text
ΔU = U(t) - U(t-1)
ΔM = M(t) - M(t-1)
ΔL = L(t) - L(t-1)
```

- `Δ > 0`：本轨向上；
- `Δ < 0`：本轨向下；
- `Δ ≈ 0`：本轨走平。

### 2.3 上下轨间距

```text
UpperGap = U - M
LowerGap = M - L
Width = U - L
NormalizedWidth = (U - L) / M
```

- `Width` 增大：开口；
- `Width` 减小：收口；
- `Width` 基本不变：通道宽度稳定。

### 2.4 宽度变化速度

```text
WidthSpeed = NormalizedWidth(t) - NormalizedWidth(t-1)
WidthAcceleration = WidthSpeed(t) - WidthSpeed(t-1)
```

- `WidthSpeed > 0`：正在扩张；
- `WidthSpeed < 0`：正在收缩；
- `WidthAcceleration > 0`：扩张加速或收缩减速；
- `WidthAcceleration < 0`：扩张减速或收缩加速。

### 2.5 三轨曲率与拐向

单轨曲率可近似为：

```text
Curve_X = ΔX(t) - ΔX(t-1)
```

其中 `X` 可以是 U、M、L。

- 原本向上且 `Curve_X < 0`：上行速度减弱；
- 原本向下且 `Curve_X > 0`：下行速度减弱；
- 轨道方向由正变负：向下拐头；
- 轨道方向由负变正：向上拐头。

## 三、三轨状态编码

每根已收盘 K 线，将三轨分别编码：

- `↑`：向上；
- `→`：走平；
- `↓`：向下。

排列顺序固定为：

```text
上轨 / 中轨 / 下轨
```

例如：

- `↑ / ↑ / ↑`：三轨同步向上；
- `↓ / ↓ / ↓`：三轨同步向下；
- `↑ / → / ↓`：上下分离、中轨走平，典型双向开口；
- `↓ / → / ↑`：上下靠拢、中轨走平，典型收口；
- `→ / ↑ / ↑`：上轨停滞，中下轨上移，上行空间受压；
- `↓↓ / ↓ / →`：上中轨下行、下轨趋平，下跌动能可能衰减。

为减少一根 K 线噪声，普通状态需持续 2 根收盘 K 线确认；反转预警可以即时记录，但不能直接视为反转确认。

## 四、方向确认信号

## D01：多头方向初步建立

### 三轨条件

1. 中轨由走平转为向上，或 `Slope_M > ε`；
2. 下轨率先或同步向上；
3. 上轨未明显向下；
4. 状态至少持续 2 根 K 线。

常见状态：

```text
→ / ↑ / ↑
↑ / ↑ / ↑
```

### 逻辑

- 中轨上行表示价格中枢抬高；
- 下轨上行表示下方波动边界抬高；
- 下方支撑结构正在上移；
- 上轨不向下意味着上行空间没有被主动压缩。

### 信号性质

**看多方向确认，强度为中等。**

它可以辅助过滤空头信号，但不等于立即开多。

---

## D02：多头方向完全确认

### 三轨条件

1. `U、M、L` 全部向上；
2. `Slope_U > 0`、`Slope_M > 0`、`Slope_L > 0`；
3. 中轨连续至少 3 根上行；
4. 三轨没有出现明显收口扭转。

状态：

```text
↑ / ↑ / ↑
```

### 逻辑

三条轨道整体上移，说明波动区间、价格中枢和下方边界都在抬高，是最清晰的多头结构。

### 信号性质

**多头方向正式确认。**

用于：

- 只保留或寻找多头机会；
- 降低逆势做空信号权重；
- 对已有多单提供继续持有依据。

---

## D03：空头方向初步建立

### 三轨条件

1. 中轨由走平转为向下，或 `Slope_M < -ε`；
2. 上轨率先或同步向下；
3. 下轨未明显向上；
4. 状态至少持续 2 根 K 线。

常见状态：

```text
↓ / ↓ / →
↓ / ↓ / ↓
```

### 逻辑

- 中轨下行表示价格中枢下移；
- 上轨下行表示上方波动边界下降；
- 上方压力结构正在下移；
- 下轨不向上，说明下跌空间尚未明显收缩。

### 信号性质

**看空方向确认，强度为中等。**

---

## D04：空头方向完全确认

### 三轨条件

1. `U、M、L` 全部向下；
2. `Slope_U < 0`、`Slope_M < 0`、`Slope_L < 0`；
3. 中轨连续至少 3 根下行；
4. 三轨没有出现明显收口扭转。

状态：

```text
↓ / ↓ / ↓
```

### 信号性质

**空头方向正式确认。**

用于：

- 只保留或寻找空头机会；
- 降低逆势做多信号权重；
- 对已有空单提供继续持有依据。

## 五、趋势强弱信号

## S01：多头趋势增强

### 三轨条件

1. 三轨总体向上；
2. 中轨上行斜率增大；
3. 上轨上行速度快于中轨，即 `ΔU > ΔM > 0`；
4. 带宽扩大，`WidthSpeed > 0`；
5. 下轨没有向下张开。

典型状态：

```text
上轨快速上行
中轨稳定上行
下轨缓慢上行或近似平行上行
```

### 逻辑

价格中枢继续上移，同时上方边界加速打开，说明上行波动和趋势空间共同增强。

### 信号性质

**多头趋势增强。**

用于已有多单的持有或加仓辅助确认，不单独触发加仓。

---

## S02：空头趋势增强

### 三轨条件

1. 三轨总体向下；
2. 中轨下行斜率绝对值增大；
3. 下轨下行速度快于中轨，即 `ΔL < ΔM < 0`；
4. 带宽扩大；
5. 上轨没有向上张开。

### 逻辑

价格中枢继续下移，下方边界加速向下打开，说明下行空间和下跌波动共同增强。

### 信号性质

**空头趋势增强。**

---

## S03：稳定多头通道

### 三轨条件

1. 三轨均向上；
2. 三轨斜率方向一致，差异较小；
3. 带宽基本稳定；
4. 状态持续至少 5 根 K 线。

可量化为：

```text
Width 近 5 根变化不超过 ±10%
max(Slope_U, Slope_M, Slope_L)
- min(Slope_U, Slope_M, Slope_L) 较小
```

### 逻辑

布林带整体向上平移而非剧烈开口，说明上涨趋势较稳定，不一定处于爆发阶段，但持续性通常好于快速扩张。

### 信号性质

**多头趋势稳定，强度中等，持续性较好。**

---

## S04：稳定空头通道

### 三轨条件

1. 三轨均向下；
2. 三轨斜率方向一致且差异较小；
3. 带宽基本稳定；
4. 状态持续至少 5 根 K 线。

### 信号性质

**空头趋势稳定，强度中等，持续性较好。**

---

## S05：双向剧烈扩张

### 三轨条件

```text
上轨向上
中轨走平或方向不明确
下轨向下
带宽快速扩大
```

状态：

```text
↑ / → / ↓
```

### 逻辑

波动率急剧上升，但价格中枢尚未给出明确方向。它可能出现在：

- 高波动震荡；
- 消息行情；
- 多空快速争夺；
- 趋势启动前的方向选择阶段。

### 信号性质

**波动强、方向弱。**

不得把“开口扩大”直接解释为趋势增强，必须等待中轨方向及三轨同向确认。

---

## S06：趋势过热预警

### 多头过热

1. 上轨上行持续加速；
2. 带宽处于最近 120 根 K 线的 90% 以上分位；
3. 中轨仍上行，但斜率不再增加；
4. 下轨走平或开始向下。

### 空头过热

1. 下轨下行持续加速；
2. 带宽处于最近 120 根 K 线的 90% 以上分位；
3. 中轨仍下行，但斜率绝对值不再增加；
4. 上轨走平或开始向上。

### 逻辑

单侧边界继续快速外扩，但中轨没有同步加速，说明波动率扩张速度超过趋势中枢移动速度，行情可能进入情绪化末端。

### 信号性质

**趋势仍在，但追仓风险上升。**

动作建议：停止追涨或追跌，已有盈利仓进入保护状态。

---

## 六、趋势衰减信号

## W01：多头动能减弱

### 三轨条件

1. 中轨仍向上；
2. 上轨由快速上行变为缓慢上行或走平；
3. 下轨继续向上；
4. 带宽开始缩小。

常见状态：

```text
→ / ↑ / ↑
```

### 逻辑

下方边界和价格中枢仍在上移，说明多头结构尚未破坏；但上轨停止扩张，上行空间被压缩，多头动能开始衰减。

### 信号性质

**多头趋势减弱，不是空头反转确认。**

动作建议：禁止继续追多，已有多单考虑收紧保护条件。

---

## W02：空头动能减弱

### 三轨条件

1. 中轨仍向下；
2. 下轨由快速下行变为缓慢下行或走平；
3. 上轨继续向下；
4. 带宽开始缩小。

常见状态：

```text
↓ / ↓ / →
```

### 逻辑

上方压力和价格中枢仍在下降，但下方边界不再继续打开，下跌空间开始收缩。

### 信号性质

**空头趋势减弱，不是多头反转确认。**

---

## W03：多头通道收口

### 三轨条件

```text
上轨向下或走平
中轨向上或走平
下轨向上
带宽连续缩小
```

典型状态：

```text
↓ / ↑ / ↑
↓ / → / ↑
→ / ↑ / ↑
```

### 逻辑

下轨抬升、上轨下降，波动区间被压缩。原有多头趋势可能进入：

- 高位整理；
- 趋势暂停；
- 变盘准备；
- 潜在顶部构筑。

### 信号性质

**多头结束预警，但方向尚未反转确认。**

---

## W04：空头通道收口

### 三轨条件

```text
上轨向下
中轨向下或走平
下轨向上或走平
带宽连续缩小
```

### 逻辑

上下轨相互靠拢，原有空头波动空间被压缩，可能进入低位整理或筑底阶段。

### 信号性质

**空头结束预警，但方向尚未反转确认。**

## 七、行情反转监测

反转必须分为“预警—结构转折—正式确认”三个阶段，不能因单条轨道拐头就直接判断反转。

## R01：多转空一级预警

### 三轨条件

1. 原状态为多头方向确认；
2. 上轨率先走平或向下；
3. 中轨仍向上，但斜率连续减小；
4. 带宽缩小。

常见状态变化：

```text
↑ / ↑ / ↑
→
→ / ↑ / ↑
```

### 含义

上行空间停止扩展，多头仍保持结构优势，但动能已经衰减。

### 动作级别

- 停止加多；
- 多单进入保护状态；
- 不允许仅凭此信号开空。

---

## R02：多转空二级预警

### 三轨条件

1. 上轨已经向下；
2. 中轨走平；
3. 下轨仍向上或走平；
4. 三轨明显收口。

典型状态：

```text
↓ / → / ↑
```

### 含义

上涨通道失去统一方向，波动区间压缩，多头趋势已经结束或暂停，市场进入方向选择。

### 动作级别

- 多单减仓辅助信号；
- 禁止新增多单；
- 等待中轨与下轨转向确认空头。

---

## R03：多转空结构转折

### 三轨条件

1. 上轨持续向下；
2. 中轨由走平转为向下；
3. 下轨由向上转为走平或向下；
4. 状态持续 2 根 K 线。

常见状态：

```text
↓ / ↓ / →
↓ / ↓ / ↓
```

### 含义

价格中枢开始下移，上方压力持续下降，下方支撑也不再抬升，多头结构已被破坏。

### 动作级别

**空头方向初步确认。**

可作为：

- 多单退出确认；
- 空头策略开始寻找入场条件的许可信号。

---

## R04：多转空正式确认

### 三轨条件

1. 三轨全部向下；
2. 中轨向下持续至少 3 根；
3. 带宽由收缩转为重新扩大；
4. 下轨向下速度不低于中轨。

状态演变：

```text
↑ / ↑ / ↑
→ / ↑ / ↑
↓ / → / ↑
↓ / ↓ / →
↓ / ↓ / ↓，并重新开口
```

### 含义

反转完成从“原趋势衰减—三轨收口—中轨转向—反向扩张”的全过程。

### 动作级别

**空头反转正式确认。**

---

## 八、震荡与变盘监测

## C01：水平窄轨震荡

### 三轨条件

1. 三轨均近似走平；
2. 带宽低于最近 120 根的 30% 分位；
3. 带宽变化速度接近零。

状态：

```text
→ / → / →
```

### 含义

趋势方向弱、波动率低，市场处于压缩状态。

### 辅助结论

- 趋势信号降权；
- 不追涨、不追跌；
- 监测后续三轨重新开口的方向。

---

## C02：收口进行中

### 三轨条件

```text
上轨向下
下轨向上
中轨走平或斜率持续减弱
带宽连续至少 3 根缩小
```

### 含义

原有波动正在被压缩，可能处于：

- 趋势结束阶段；
- 震荡整理阶段；
- 新趋势酝酿阶段。

收口本身不提供方向。

---

## C03：收口后向上开口

### 三轨条件

1. 前期存在 C01 或 C02；
2. 上轨由走平转为向上；
3. 中轨由走平转为向上；
4. 下轨走平或随后向上；
5. 带宽由缩小转为扩大。

### 信号性质

**向上变盘候选。**

若随后形成 `↑ / ↑ / ↑`，升级为多头方向确认。

---

## C04：收口后向下开口

### 三轨条件

1. 前期存在 C01 或 C02；
2. 下轨由走平转为向下；
3. 中轨由走平转为向下；
4. 上轨走平或随后向下；
5. 带宽由缩小转为扩大。

### 信号性质

**向下变盘候选。**

若随后形成 `↓ / ↓ / ↓`，升级为空头方向确认。

---

## C05：无方向扩张

### 三轨条件

1. 上轨向上；
2. 下轨向下；
3. 中轨走平；
4. 带宽快速扩大。

### 信号性质

**高波动、无方向。**

此状态不能被归类为多头开口或空头开口。等待中轨转向后再确认方向。

---

## 九、异常与风险监测

## A01：上轨独立上翘

状态：

```text
↑ / → / →
或 ↑ / → / ↓
```

含义：上方波动突然增加，但价格中枢尚未上移。

可能是：

- 向上试探；
- 短时插针；
- 高波动扩张；
- 多头趋势启动前兆。

结论：只记录预警，等待中轨上行确认。

## A02：下轨独立下弯

状态：

```text
→ / → / ↓
或 ↑ / → / ↓
```

含义：下方波动突然增加，但价格中枢尚未下移。

结论：只记录预警，等待中轨下行确认。

## A03：三轨方向频繁切换

定义：最近 6 根 K 线内，中轨方向编码切换至少 3 次。

含义：行情缺乏持续方向，三轨信号可靠性下降。

动作建议：

- 所有方向确认信号降一级；
- 暂停使用三轨状态作为加仓依据；
- 等待至少 3 根同方向中轨状态。

## A04：极端宽轨

定义：带宽位于最近 120 根 K 线的 95% 以上分位。

含义：市场处于历史相对高波动区域。

动作建议：

- 不因宽轨本身追单；
- 检查中轨是否同步加速；
- 若中轨未同步，视为过热或无方向扩张风险；
- 已有仓位优先保护利润。

---

## 十、趋势阶段状态机

建议将每个周期的 BOLL 三轨归入以下阶段之一：

| 状态编号 | 阶段 | 三轨特征 | 结论 |
|:---:|:---|:---|:---|
| P0 | 无方向震荡 | 三轨走平，宽度稳定 | 无趋势 |
| P1 | 波动压缩 | 上轨下、下轨上、带宽缩小 | 等待变盘 |
| P2-L | 多头萌芽 | 中轨转上、下轨抬升 | 多头预备 |
| P2-S | 空头萌芽 | 中轨转下、上轨下降 | 空头预备 |
| P3-L | 多头确认 | 三轨同向上 | 多头趋势 |
| P3-S | 空头确认 | 三轨同向下 | 空头趋势 |
| P4-L | 多头增强 | 上轨加速、带宽扩大、中轨上 | 多头增强 |
| P4-S | 空头增强 | 下轨加速、带宽扩大、中轨下 | 空头增强 |
| P5-L | 多头衰减 | 上轨停滞、带宽缩小、中轨仍上 | 停止追多 |
| P5-S | 空头衰减 | 下轨停滞、带宽缩小、中轨仍下 | 停止追空 |
| P6 | 转折观察 | 中轨走平、三轨收口 | 减仓观察 |
| P7-L | 反转为多 | 三轨转上并重新扩张 | 多头反转确认 |
| P7-S | 反转为空 | 三轨转下并重新扩张 | 空头反转确认 |
| PX | 无方向扩张 | 上轨上、下轨下、中轨平 | 高波动、方向未知 |

状态切换原则：

1. 普通状态至少持续 2 根 K 线才生效；
2. 正式趋势确认要求中轨持续同向至少 3 根；
3. 反转必须经过中轨转向，不能只凭上轨或下轨变化确认；
4. 带宽扩大只表示波动增强，必须结合中轨方向判断多空；
5. 从 P3/P4 直接跳到反向 P3/P4 时，应检查是否存在数据异常或极端行情。

## 十二、置信度评分建议

基础分从 0 开始：

### 多头评分

| 条件 | 分值 |
|:---|---:|
| 中轨向上 | +25 |
| 三轨全部向上 | +20 |
| 中轨连续 3 根向上 | +15 |
| 上轨向上速度大于中轨 | +10 |
| 带宽温和扩大 | +10 |
| 稳定上行通道持续 5 根 | +10 |
| 上轨走平或向下 | -15 |
| 中轨斜率连续减弱 | -15 |
| 三轨明显收口 | -15 |
| 极端宽轨且中轨未加速 | -20 |

### 空头评分

使用完全对称的规则：

| 条件 | 分值 |
|:---|---:|
| 中轨向下 | +25 |
| 三轨全部向下 | +20 |
| 中轨连续 3 根向下 | +15 |
| 下轨向下速度大于中轨 | +10 |
| 带宽温和扩大 | +10 |
| 稳定下行通道持续 5 根 | +10 |
| 下轨走平或向上 | -15 |
| 中轨下行斜率连续减弱 | -15 |
| 三轨明显收口 | -15 |
| 极端宽轨且中轨未加速 | -20 |

评分解释：

- `80～100`：方向和结构高度一致；
- `60～79`：方向确认，可作为策略过滤条件；
- `40～59`：方向偏向，但确认不足；
- `20～39`：弱方向或转折观察；
- `0～19`：无有效方向。

> 多头分和空头分应分别计算，不应强制互为 `100 - 对方分数`，因为市场可能同时处于“多空都不明确”的状态。

## 十三、多周期联合监测

建议按以下层级使用：

- `2H`：大方向和趋势阶段；
- `1H`：主要方向确认与反转监测；
- `30m`：趋势增强、衰减和结构转折；
- `15m`：短线变化预警，不单独决定大方向。

### 多周期同向

当 2H、1H、30m 至少三个周期中的两个处于同方向 P3/P4，且更高周期不反向时，定义为多周期方向确认。

### 低周期领先反转

例如：

```text
15m：多转空二级预警
30m：多头衰减
1H：多头确认
2H：多头确认
```

结论只能是：

- 短周期回调风险上升；
- 不能直接判断大级别趋势反转。

只有当反转依次扩散到 30m、1H，并出现中轨转向，才升级为大级别反转。

### 周期冲突

- 高周期多、低周期空：视为多头趋势中的回调候选；
- 高周期空、低周期多：视为空头趋势中的反弹候选；
- 高周期走平、低周期同向增强：可能是新趋势早期，但需等待高周期确认。

## 十四、信号与交易动作的边界

本体系输出的是辅助信号，不直接等同于交易命令：

| 监测结果 | 可辅助的交易决策 |
|:---|:---|
| 方向初步建立 | 允许对应方向策略开始寻找入场点 |
| 方向完全确认 | 过滤逆势交易，支持顺势持仓 |
| 趋势增强 | 支持持仓或加仓，但仍需独立入场条件 |
| 稳定趋势通道 | 支持继续持有 |
| 趋势衰减 | 停止追仓、收紧风险 |
| 一级反转预警 | 禁止原方向继续加仓 |
| 二级反转预警 | 原方向减仓观察 |
| 结构转折 | 原方向退出，允许反向策略准备 |
| 正式反转确认 | 允许反向策略寻找入场或按规则反手 |
| 收口 | 等待，不预测方向 |
| 无方向扩张 | 降低仓位，等待中轨确认 |

实际开仓、加仓、减仓数量、固定止盈和风险上限，仍遵守 `交易与仓位管理规则.md`。

## 十五、信号优先级

同一根 K 线出现多个监测信号时：

1. **异常与风险信号**；
2. **正式反转确认**；
3. **结构转折**；
4. **二级反转预警**；
5. **趋势衰减**；
6. **方向完全确认**；
7. **趋势增强**；
8. **方向初步建立**；
9. **一级反转预警**；
10. **震荡、收口或无方向扩张提示**。

风险类信号优先于增强类信号。例如三轨仍向上但出现极端宽轨且中轨减速时，应输出“多头趋势仍在、过热风险上升”，而不是只输出“多头增强”。

## 十六、关键使用原则

1. **中轨负责方向**：没有中轨转向，不确认趋势反转；
2. **上下轨负责空间和波动**：单条外轨变化只能预警，不能独立确认方向；
3. **三轨同向负责确认**：三轨同步上行或下行是最清晰的方向结构；
4. **开口不等于趋势**：上轨上、下轨下、中轨平只是波动扩大；
5. **收口不预测方向**：收口只表示波动压缩；
6. **外轨先拐是预警，中轨再拐是转折，三轨同向是确认**；
7. **趋势强弱由斜率与宽度共同判断**：只看带宽会把无方向剧烈震荡误判为强趋势；
8. **已收盘 K 线确认**：盘中三轨状态仅用于观察，不写入正式信号；
9. **多周期由高到低解释**：低周期反向优先解释为回调，不直接推翻高周期趋势；
10. **本体系是过滤器和监测器**：应与价格结构、成交量或其他独立入场规则配合。

---

## 十七、回测与验证要求

正式使用前应验证：

- 不同周期适用的斜率阈值 `ε`；
- 三轨状态持续 2 根或 3 根的确认差异；
- 带宽扩大、收缩的有效百分比阈值；
- 趋势增强信号后的延续概率；
- 一级、二级反转预警转为正式反转的概率和平均耗时；
- 无方向扩张被误判为趋势的比例；
- 多周期同向时与单周期信号相比的改善程度；
- 信号延迟、最大回撤、连续错误次数及手续费影响。

> 本体系仅用于研究、监测和辅助决策，不构成投资建议或收益保证。
