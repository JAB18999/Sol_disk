# 三指标组合交易策略集（SOL 永续合约）

> 在双指标基础上再增加一个维度，形成"趋势 + 动量 + 波动率/位置"的三重过滤。
> 核心原则：三个指标各司其职，信息维度尽量不重叠。

---

## 策略一：DMI + BOLL + RSI — 全功能自适应策略

| 项目 | 内容 |
|:-----|:-----|
| **分工** | DMI 判行情（趋势/震荡），BOLL 定价格位置，RSI 确认入场 |
| **核心逻辑** | 用 ADX 自动切换策略模式——趋势市用 BOLL 突破 + RSI 顺势，震荡市用 BOLL 高抛低吸 + RSI 超买超卖 |
| **1. 行情识别** | ADX > 25 = 趋势市；ADX < 20 = 震荡市 |
| **2. 开仓** | 趋势市：突破上轨 + RSI > 50 → 做多；震荡市：触下轨 + RSI < 30 → 做多 |
| **3. 加仓** | 趋势市：回踩中轨 + RSI 从中界反弹 → 加仓 |
| **4. 止盈** | 趋势市：ADX 拐头 或 固定比例；震荡市：触上轨 或 固定比例 |
| **5. 止损** | 趋势市：跌破中轨；震荡市：突破轨线（变趋势了） |
| **优势** | 覆盖全行情，自适应切换 |

---

## 策略二：EMA + MACD + RSI — 三重动量确认策略

| 项目 | 内容 |
|:-----|:-----|
| **分工** | EMA 定大趋势方向，MACD 确认动能，RSI 找精确入场点 |
| **核心逻辑** | 三重过滤：趋势向上 + 动量向上 + 回调到位，三个条件同时满足才入场 |
| **1. 行情识别** | EMA 多头排列 = 多头趋势 |
| **2. 开仓** | EMA 多头 + MACD 零上 + RSI 回调至 40~50 后反弹 → 做多 |
| **3. 加仓** | MACD 红柱放大 + RSI 在 50 上方持续上行 → 加仓 |
| **4. 止盈** | RSI > 70 或 MACD 死叉 或 固定比例，先到先触发 |
| **5. 止损** | EMA 死叉 或 MACD 死叉 + RSI 跌破 50 |
| **优势** | 胜率最高，但交易频率最低 |
| **注意** | EMA 和 MACD 有一定重叠，RSI 提供独立维度 |

---

## 策略三：MA + DMI + MACD — 经典趋势跟踪策略

| 项目 | 内容 |
|:-----|:-----|
| **分工** | MA 定大方向，DMI 定趋势强度，MACD 定入场时机 |
| **核心逻辑** | 经典趋势跟踪三件套——均线定方向、ADX 定强度、MACD 定时机 |
| **1. 行情识别** | MA 金叉 + ADX > 25 = 趋势确立 |
| **2. 开仓** | MA 多头 + ADX 上升 + MACD 金叉确认 → 做多 |
| **3. 加仓** | ADX 持续上升 + MACD 柱状放大 + 回踩 MA_short → 加仓 |
| **4. 止盈** | ADX 从高位回落 或 固定比例止盈 |
| **5. 止损** | MA 死叉 + ADX 跌回 25 以下 → 止损 |
| **优势** | 逻辑最经典，参数最稳定，适合中长线 |

---

## 策略四：BOLL + MACD + RSI — 波动率 + 双动量策略

| 项目 | 内容 |
|:-----|:-----|
| **分工** | BOLL 定波动率和价格通道，MACD 定趋势动量，RSI 定震荡动量 |
| **核心逻辑** | 一个价格维度 + 两个动量维度三重确认，捕捉波动率突破后的趋势行情 |
| **1. 行情识别** | 布林带带宽从极值扩大 = 波动率放大，行情启动 |
| **2. 开仓** | 价格突破上轨 + MACD 红柱放大 + RSI > 60 → 做多 |
| **3. 加仓** | 回踩上轨/中轨支撑 + MACD 柱状继续放大 + RSI 维持强势 → 加仓 |
| **4. 止盈** | 带宽缩小 + MACD 柱状缩量 或 固定比例止盈 |
| **5. 止损** | 价格跌回下轨 + MACD 死叉 + RSI 跌破 50 → 三确认止损 |
| **优势** | 信号质量高，假突破少，盈亏比好 |

---

## 策略五：EMA + BOLL + DMI — 趋势通道过滤策略

| 项目 | 内容 |
|:-----|:-----|
| **分工** | EMA 定趋势方向，BOLL 定通道，DMI 定趋势强度过滤 |
| **核心逻辑** | 三重趋势过滤——只在强趋势中，顺着通道方向做回调 |
| **1. 行情识别** | EMA 多头 + ADX > 25 + 价格在中轨上方 = 强多头通道 |
| **2. 开仓** | 价格回调至 BOLL 中轨或下轨获得支撑 + EMA 方向不变 + ADX 仍高 → 做多 |
| **3. 加仓** | 价格突破上轨 + EMA 斜率加大 + ADX 上升 → 加仓 |
| **4. 止盈** | ADX 拐头 + 价格触及上轨 或 固定比例止盈 |
| **5. 止损** | 跌破中轨 + ADX 回落 → 止损 |
| **优势** | 三重过滤后胜率极高，回撤小 |
| **注意** | MA/EMA/BOLL 中轨有重叠，DMI 是独立维度 |

---

## 策略六：DMI + MACD + RSI — 动量三重确认策略

| 项目 | 内容 |
|:-----|:-----|
| **分工** | DMI 判趋势强度，MACD 判趋势动量，RSI 判震荡动量 |
| **核心逻辑** | 三个动量指标从不同角度确认趋势，只在三箭齐发时出手 |
| **1. 行情识别** | ADX > 25 = 有趋势 |
| **2. 开仓** | ADX > 25 + MACD 零上金叉 + RSI 上穿 50 → 做多（三重确认） |
| **3. 加仓** | ADX 上升 + MACD 柱状放大 + RSI 在 60 以上 → 加仓 |
| **4. 止盈** | ADX 拐头 或 MACD 死叉 或 RSI > 80，任一触发 |
| **5. 止损** | ADX 回落 + MACD 死叉 + RSI 跌破 50 → 三确认止损 |
| **优势** | 信号最可靠，但交易机会最少 |

---

## 策略七：BOLL + RSI + DMI — 震荡回归 + 趋势过滤策略

| 项目 | 内容 |
|:-----|:-----|
| **分工** | BOLL 定区间，RSI 确认超买超卖，DMI 过滤假突破 |
| **核心逻辑** | 震荡市高抛低吸，但用 DMI 监控——一旦趋势形成立刻切换方向 |
| **1. 行情识别** | ADX < 20 + 带宽收窄 = 震荡市；ADX 上升至 25 以上 = 转趋势 |
| **2. 开仓** | 震荡市：价格触下轨 + RSI < 30 → 做多；触上轨 + RSI > 70 → 做空 |
| **3. 加仓** | 二次触轨不创新低/高 + RSI 背离 → 加仓 |
| **4. 止盈** | 回归中轨 或 固定比例止盈 |
| **5. 止损** | ADX > 25 + 价格突破轨线 → 震荡转趋势，止损并反手 |
| **优势** | 震荡市赚钱，趋势市不亏甚至反手赚 |

## 策略八：MA + RSI + MACD — 均线动量三剑客策略

| 项目 | 内容 |
|:-----|:-----|
| **分工** | MA 定大趋势方向，RSI 找回调入场，MACD 确认动能和离场 |
| **核心逻辑** | 最经典的散户三件套组合——均线看方向、RSI 找点位、MACD 防顶底 |
| **1. 行情识别** | MA 多头排列 = 多头趋势 |
| **2. 开仓** | MA 多头 + RSI 回调至 40~50 反弹 + MACD 红柱 → 做多 |
| **3. 加仓** | RSI 回踩 50 支撑 + MACD 柱状放大 → 加仓 |
| **4. 止盈** | RSI > 70 或 MACD 顶背离 或 固定比例止盈 |
| **5. 止损** | MA 死叉 + MACD 死叉 + RSI 跌破 50 → 止损 |
| **优势** | 逻辑最直观，参数最常见，容易理解和调优 |

---

## 策略九：EMA + BOLL + RSI — 趋势通道波段策略

| 项目 | 内容 |
|:-----|:-----|
| **分工** | EMA 定趋势方向，BOLL 定通道上下沿，RSI 确认入场时机 |
| **核心逻辑** | 在趋势方向内，沿着布林带通道做波段——下沿买、上沿卖 |
| **1. 行情识别** | EMA 多头排列 + 价格在 BOLL 中轨上方 = 上升通道 |
| **2. 开仓** | 价格回调至下轨/中轨 + RSI < 40 后回升 + EMA 方向未变 → 做多 |
| **3. 加仓** | 价格突破上轨 + RSI 持续强势 + EMA 斜率加大 → 加仓 |
| **4. 止盈** | 价格触及上轨 + RSI > 70 或 固定比例止盈 |
| **5. 止损** | 收盘价跌破中轨 + RSI 跌破 50 → 止损 |
| **优势** | 波段节奏清晰，持仓体验好 |

## 策略十：DMI + BOLL + MACD — 三维度共振策略

| 项目 | 内容 |
|:-----|:-----|
| **分工** | DMI 判趋势强度，BOLL 判波动率，MACD 判动量方向 |
| **核心逻辑** | 三个完全独立的维度（强度、波动率、动量）叠加，捕捉大行情启动点 |
| **1. 行情识别** | ADX 从低位上升 + 布林带从收敛转扩大 = 行情启动 |
| **2. 开仓** | ADX 上穿 25 + 带宽扩大 + MACD 金叉 → 做多（三维度共振） |
| **3. 加仓** | ADX 持续上升 + 带宽持续扩大 + MACD 柱状放大 → 加仓 |
| **4. 止盈** | ADX 拐头 + 带宽收窄 + MACD 柱状缩量（至少两个触发） |
| **5. 止损** | ADX 回落 + 价格跌回中轨 + MACD 死叉 → 止损 |
| **优势** | 三个维度完全独立，信号质量最高，专门抓大行情 |
| **定位** | 旗舰策略，一年交易次数不多，但每次都是大行情 |

## 三指标 vs 双指标的取舍

| 维度 | 双指标 | 三指标 |
|:-----|:------:|:------:|
| 胜率 | 中等 | 更高 |
| 交易频率 | 中等 | 更低 |
| 复杂度 | 简单 | 较复杂 |
| 过拟合风险 | 低 | 更高（参数多） |
| 适合人群 | 初学者 / 高频交易 | 稳健型 / 中长线 |

> **原则**：指标不是越多越好。每增加一个指标，胜率可能提高，但交易机会会减少，且过拟合风险增大。三指标策略更适合"少而精"的交易风格。

## 指标互补性总览

| 指标 | 提供的维度 | 同类指标 |
|:-----|:---------|:---------|
| MA / EMA | 趋势方向 | 同类，二选一即可 |
| MACD | 趋势动量、柱状领先信号 | 和 EMA 部分重叠 |
| RSI | 震荡动量、超买超卖 | 独立 |
| BOLL | 波动率、价格通道、中轨趋势 | 中轨 = MA，部分重叠 |
| DMI | 趋势强度（ADX）、多空力量对比 | 完全独立（ADX 独一无二） |

> **最佳搭配公式**：1 个趋势方向指标（MA/EMA）+ 1 个动量指标（MACD/RSI）+ 1 个波动率/强度指标（BOLL/DMI）
